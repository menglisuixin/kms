# KMS管理系统

基于若依框架开发的KMS管理系统，专注于服务器关键指标的实时监控与管理，通过定时任务机制实现系统状态的持续追踪，为运维决策提供数据支持。

## 系统功能

### 核心监控功能

1. **多维度数据采集**
   - CPU监控：实时采集总使用率、用户使用率、系统使用率及空闲率
   - 内存监控：追踪内存总容量、已用内存、空闲内存及使用率
   - 磁盘监控：监控各磁盘分区的路径、类型、总容量、已用空间、空闲空间及使用率

2. **数据采集机制**
   - 基于定时任务调度，每分钟自动采集一次系统数据
   - 所有指标数据实时存储，支持历史数据查询与趋势分析
   - 数据有效性标记，确保监控数据的可靠性

3. **可视化监控面板**
   - CPU使用率趋势图：展示用户使用率、系统使用率和空闲率的动态变化
   - 内存使用情况图表：直观呈现内存使用占比与趋势
   - 磁盘状态监控：以水平条形图展示各磁盘分区的使用情况
   - 实时数据表格：详细列出各时间点的三维指标数据，支持分页与筛选

4. **系统维护功能**
   - 模块状态监控：实时检查数据采集器、数据分析器、数据库服务、后端服务的运行状态
   - 阈值配置管理：可配置CPU、内存、磁盘使用率的预警阈值
   - 预警级别设置：支持无预警、基础预警、中级预警、严重预警四级配置

### 内置功能

1.  操作日志：系统正常操作日志记录和查询；系统异常信息日志记录和查询。
2.  登录日志：系统登录日志记录查询包含登录异常。
3.  定时任务：在线（添加、修改、删除）任务调度包含执行结果日志，支持系统监控数据采集任务配置。
4.  服务监控：监视当前系统CPU、内存、磁盘、堆栈等相关信息。

## 数据展示与分析

- 实时数据展示：当前系统CPU、内存、磁盘的实时状态
- 历史趋势分析：展示指定时间段内的指标变化趋势
- 多维度对比：支持不同时间点的指标数据对比分析
- 异常标记：当指标超过设定阈值时，自动标记异常数据

## 系统特点

- 轻量级架构：基于若依框架开发，部署简单，维护成本低
- 实时性强：分钟级数据采集，确保监控的及时性
- 可扩展性好：支持新增监控指标与扩展监控维度
- 可视化程度高：丰富的图表展示，直观呈现系统状态
- 操作简便：简洁易用的界面设计，降低使用门槛

通过KMS管理系统，管理员可以全面掌握服务器的运行状态，及时发现并处理潜在的性能问题，保障系统的稳定运行。
